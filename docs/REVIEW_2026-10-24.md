# Sửa theo góp ý ngày 2026-10-24

Mọi thay đổi dưới đây **không đổi giả thuyết đã đăng ký**: họ Holm của H1 (ViMMRC + Belebele × 3 tỉ lệ, 4 ô α = 0) và H2 (ViNLI NFR) giữ nguyên. Các ô và phân tích mới là mô tả (`analyze.py --hypothesis none`) hoặc chạy trước test trên dev.

## Cắt chi phí (không đổi giả thuyết)

| Việc | Code |
|---|---|
| Logit một lần | `SyllableScorer` lưu logit âm tiết xuống `VIWORD_LOGIT_CACHE` (mặc định `cache/logits`), khóa = dấu vân tay checkpoint (kích thước + mtime trọng số) × nội dung tài liệu; encoder chỉ nạp khi trượt cache, nên π, α, ngân sách, reader, gộp từ/âm tiết đều chạy trên CPU |
| Bỏ trùng lượt gọi reader | `evaluate.generate_cached`: mỗi prompt khác nhau gọi một lần mỗi lượt chạy; `VIWORD_READER_CACHE` (mặc định `cache/reader_outputs.jsonl`) dùng lại giữa các stage; khóa gồm reader, system prompt, giới hạn token, prompt |
| LLMLingua-2 | `_ForwardCache`: tìm kiếm nhị phân theo `rate` chỉ chạy bộ phân loại một lần mỗi chunk. LLMLingua (perplexity) không bọc |
| Reader thứ hai | `SECOND_READER_FULL=0` (mặc định): (i), (iv), LLMLingua-2 công bố, truncation, chỉ 1/3; không chạy cận trên thầy |
| VietNews | `VIETNEWS_FULL=0`: các hệ thống Bảng 5 (H2) + none, no_context, lead, truncation, LLMLingua-2, (i). Giới hạn token tóm tắt giữ 256 |
| LongLLMLingua | `LONGLLMLINGUA=0` để bỏ |
| Sinh ngắn + prefix cache | `max_tokens` nli/mc/qa đã là 32; vLLM bật `enable_prefix_caching`. Tỉ lệ câu trả lời không đọc được vẫn được `analyze.py` gắn ⚠ khi > 2% |
